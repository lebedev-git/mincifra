## GD — Депонирование (Роспатент) 🔲 ← авто по файлам

Отдельный этап между G1 и G2. **Опциональный по закону** (Путь 1 усиления авторства),
но включён в общий процент готовности как полноценный этап. Пункты закрываются
**автоматически**, когда на вкладке «Документы» появляется соответствующий файл
(загружен вручную или сгенерирован кнопкой «Сгенерировать»). Свидетельство даёт
госрегистрация ДоЭВМ на `fips.ru` — не то же, что акт фиксации с SHA-256.

- [ ] Снимок версии кода + акт фиксации (SHA-256) — `dep_snapshot` _(готовит «Мастер подготовки»)_
- [ ] Реферат программы — `dep_referat` _(генерируется)_
- [ ] Фрагмент исходного кода (до 50 стр.) — `dep_codefrag` _(генерируется; обрезка «первые 25 + последние 25», `03_docs/depon.js`)_
- [ ] Цепочка прав: служебные задания, договоры, акты — `dep_chain` _(генерируется, подписывает юрист; учитывается в трекере)_
- [ ] Заявление в Роспатент, подписанное УКЭП — `dep_statement` _(генерируется, подписать УКЭП)_
- [ ] Свидетельство о госрегистрации ПО — `dep_cert` _(приходит из Роспатента, загрузить готовое)_

**Артефакты гейта:** файлы `dep_*` в разделе «Документы» · закрывают пункт G1 «исключительное право».

## GA — Отчуждение права (физлицо → ООО) 🔲 ← авто по файлам

Схема B: депонирование оформлено на **автора-физлицо**, но правообладателем для реестра
Минцифры выступает **ООО**. Право передаётся по договору отчуждения (ст. 1234 ГК РФ).
Доступно после получения свидетельства ПрЭВМ. Статус права вычисляется в
`platform/core/rights.js` (`dep_granted → assigned`).

- [ ] Договор отчуждения исключительного права (ст. 1234 ГК) — `dep_assign_contract` _(генерируется, подписывает юрист)_
- [ ] Акт приёма-передачи — `dep_assign_act` _(генерируется)_

**Артефакты гейта:** файлы `dep_assign_*` · переводят статус права в «Договор отчуждения подписан».

## GR — Регистрация перехода права в ФИПС (ст. 1232) 🔲 ← авто по факту

**Обязательна**, раз программа прошла госрегистрацию в Роспатенте: переход
исключительного права по договору отчуждения сам подлежит госрегистрации в ФИПС
(ст. 1232 п. 2, ст. 1262 п. 5 ГК РФ). Без регистрации переход **считается несостоявшимся**
(ст. 1232 п. 6) — реестр Минцифры завернёт цепочку прав. Реестр (G4) открывается только
после этого шага (`rights.js`: `assigned → transfer_registered`, `canSubmitReestr`).

- [ ] Заявление о регистрации отчуждения (ст. 1232 п.2, 1262 п.5) — `dep_assign_register` _(генерируется, подать в ФИПС)_
- [ ] Уведомление ФИПС о состоявшейся регистрации перехода — отметка `rights.transferRegistered` + № и дата

**Артефакты гейта:** `dep_assign_register` · отметка регистрации перехода в карточке.

## G5 — Требования к ПО (ПП № 1236, п. 5) 🔲 ← авто из выписки акта

Проверяется командой `check_compliance` / экраном соответствия. Пункты и их дословные
формулировки живут в `99_reference/pp1236.json`, статус вычисляет `platform/core/criteria.js`.

- [ ] подп. «а» — исключительное право у российского лица; контроль > 50% **голосов**
- [ ] подп. «б» — правомерно введено в оборот, свободно реализуется на всей территории РФ
- [ ] подп. «в» — выплаты иностранным лицам (включая агентов и представителей) < 30% выручки
- [ ] подп. «г» — нет сведений, составляющих государственную тайну
- [ ] подп. «д», «е» — сертификат и лицензия _(только для средств защиты конфиденциальной информации)_
- [ ] подп. «ж» — нет принудительного обновления и управления из-за рубежа
- [ ] подп. «з» — гарантийное обслуживание и техподдержка российским лицом
- [ ] подп. «и» — хранение исходного текста, объектного кода и компиляция на территории РФ
- [ ] подп. «к» — средства управления лицензионными ключами на территории РФ
- [ ] подп. «л» — графический интерфейс на русском языке
- [ ] подп. «м» — совместимость не менее чем с 2 доверенными ОС _(по графику волн для класса)_
- [ ] подп. «н» — выручка от своей группы лиц не более 30% _(только для госкомпаний)_

**Артефакт гейта:** ответ `check_compliance` с `canDeclareCompliance: true` — основание
подписать декларацию по п. 10 подп. «г».

## G3 — Техническая готовность (Блок 2) 🔲 ← авто-проверки

Запуск: `node 02_checks/run_checks.js product.json`

- [ ] **Правило 30 %** — выплаты иностранцам / выручка по продукту < 30 % (`foreign_payments`)
- [ ] **Лицензии OSS** — нет GPL/AGPL в ядре, нет «no-license»/санкционных компонентов (`license_scan` по SBOM)
- [ ] **Сетевой аудит** — нет обязательных обращений к зарубежным доменам (`network_audit` по HAR)
- [ ] **Страница продукта** — доступность и локализация ресурсов (`page_check`)
- [ ] Сводный отчёт `02_checks/last_report.md` = **PASS**. Внимание: `SKIP` (нет SBOM/HAR) тянет итог в `WARN` — зелёного без входных данных не бывает

**Артефакты гейта:** `last_report.md` · SBOM · HAR
