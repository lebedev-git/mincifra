# Нормативный справочник

Опорная нормативная база пайплайна и перечень значений, требующих сверки перед подачей.

## Нормативный костяк (стабильно)

| Акт | Что регулирует |
| --- | --- |
| **ст. 12.1 ФЗ № 149-ФЗ** (введена 188-ФЗ) | Запрет закупки иностранного ПО при наличии аналога в реестре (основа 44-ФЗ/223-ФЗ). |
| **ПП РФ № 1236 от 16.11.2015** | Правила формирования и ведения реестра, классификатор, требования к ПО, финансовый критерий 30%. |
| **ПП РФ № 325 от 23.03.2017** | Доптребования к офисному ПО, ОС, СУБД (если применимо к классу). |
| **ст. 1259–1260, 1262, 1295 ГК РФ** | Охрана произведения, госрегистрация программы для ЭВМ, служебные произведения. |
| **ст. 149 НК РФ** | Освобождение от НДС при реализации прав на ПО из реестра. |
| Приказы Минцифры | Регламент рассмотрения заявлений, состав экспертного совета. |

Терминология: «реестр отечественного ПО» = **Единый реестр российских программ для ЭВМ и баз данных** (ведёт Минцифры, `reestr.digital.gov.ru`). Отдельно существует реестр ЕАЭС; для 44-ФЗ ключевой — российский.

## ⚠️ Значения под обязательную сверку (`СВЕРИТЬ`)

Эти параметры менялись в 2023–2025 гг. Проверять на `reestr.digital.gov.ru` и в действующей редакции ПП № 1236 **непосредственно перед подачей**:

| Что сверять | Где | Где используется в пайплайне |
| --- | --- | --- |
| Актуальный **код класса ПО** по классификатору | reestr.digital.gov.ru / ПП № 1236 прил. | `product.json` → `product.class`; трекер G0 |
| **Доптребования** по совместимости с российскими ОС/процессорами для класса | ПП № 325 / приказы | `product.json` → `tech.supportedOS`; проверка `page_check`/G0 |
| **Процедурные сроки** этапов (формальная/содержательная экспертиза) | регламент Минцифры | трекер G4/G5 (ориентир 1–3 мес.) |
| **Форматы и лимиты вложений** в АИС «Реестр» | reestr.digital.gov.ru | трекер G4; опись досье |
| Перечень обязательных **сведений в заявлении** | форма на портале | трекер G4; «Сведения о соответствии» |

> Значение порога **30%** (финансовый критерий) и запрет иностранного контроля — стабильны и в сверке не нуждаются; сверять нужно процедуру и классификацию.

## Стоп-факторы Экспертного совета (из аналитической записки)

- **Санкционные СУБД:** Oracle, MS SQL Server, SAP HANA → PostgreSQL, ClickHouse, YDB, Postgres Pro.
- **Западная инфраструктура:** GitLab.com, AWS/Azure → перенос CI/CD и продакшена в РФ (Yandex Cloud, Selectel).
- **«Call home»:** Google Fonts, зарубежные CDN, иностранная телеметрия → локализация/удаление (проверяется `network_audit`).
- **Английский GUI:** интерфейс обязан быть на русском (код/комментарии — можно на английском).
- **Windows-only:** с 2026 г. — поддержка ≥ 2 российских ОС (Astra Linux, РЕД ОС, Alt Linux) `СВЕРИТЬ для класса`.
- **OSS-блокеры:** GPL/AGPL в ядре проприетарного продукта; AGPL критична для SaaS (проверяется `license_scan`).
